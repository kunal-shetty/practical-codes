# Practical Codes Repository

This repository contains a collection of practical coding assignments, projects, and experiments completed during the first and second years of college (Semesters 1-4).

## 📂 Repository Structure

The codes are organized by language and domain for easy navigation:

### **Programming Languages**
- **[CCodes](./CCodes/)**: Fundamental C programs covering data structures, algorithms, and system concepts.
- **[CppCodes](./CppCodes/)**: C++ programs focusing on Object-Oriented Programming (OOP) concepts, file handling, and projects.
- **[JavaCodes](./JavaCodes/)**: Java practicals including OOPs concepts, exception handling, and applets.
- **[PythonCodes](./PythonCodes/)**: Basic Python scripts and exercises.
- **[PythonPracticals](./PythonPracticals/)**: Comprehensive Python practical assignments.

### **Web Development**
- **[WebDevelopment](./WebDevelopment/)**: HTML, CSS, JavaScript, and PHP projects.
  - Includes `WebTech` and `PracticePortfolio` projects.

### **Databases**
- **[PlSql](./PlSql/)**: PL/SQL scripts and queries for database management.

### **Data Structures & Algorithms**
- **[DataStructuresAndAlgorithms](./DataStructuresAndAlgorithms/)**: Implementation of core data structures and algorithms.
  - `Arrays`, `LinkedLists`, `Stack`, `Queue`, `Tree`, `Graph`, `SortingAlgorithms`, `Searching`

### **Others**
- **[ComputerGraphics](./ComputerGraphics/)**: Computer Graphics practicals.


## 🚀 Highlights
- **Library Management System**: A C++ project managing books and members.
- **Tic-Tac-Toe**: A console-based game implemented in both C and C++.
- **Web Portfolio**: A personal portfolio website.
